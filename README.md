## Organização

```
empresa/          documentação, modelos e materiais da empresa de sites
SaS/              produtos de software, um por pasta

```

Cada projeto tem o próprio README, a própria documentação numerada e o próprio CHANGELOG.

## O que não entra neste repositório

- Dados de clientes, tabela de preços e valores de propostas (ficam no vault de gestão, fora do Git).
- Senhas, tokens e acessos (ficam num gerenciador de senhas).
- O código dos sites de clientes (cada um tem o próprio repositório).
