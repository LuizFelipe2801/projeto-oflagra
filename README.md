# Nome a definir

`ÁREA` Sites e presença digital para comércio local

`REGIÃO` Belo Horizonte e Região Metropolitana

`FUNDAÇÃO` 2026

Sites para pequenos comércios de BH e região: lojas, salões, pet shops, oficinas, academias. Cada entrega é um site rápido no celular, com catálogo ou serviços, botão direto para o WhatsApp e o negócio aparecendo no Google. Junto com o site vão um vídeo de apresentação, a documentação para o dono e um relatório de resultado em 30, 60 e 90 dias.

O diferencial não é "fazer site". É entregar um produto pronto, medido e documentado, para um público que hoje vive só do Instagram e do WhatsApp.

## O que não entra neste repositório

Este repositório documenta a empresa. Ele **não guarda**:

- Dados de clientes: nome de contato, telefone, endereço, números de venda. Esses ficam no vault de gestão, fora do Git.
- Tabela de preços e valores de propostas.
- Senhas, tokens e acessos de domínio ou hospedagem. Use um gerenciador de senhas.
- O código dos sites dos clientes. Cada projeto tem o próprio repositório.

O motivo é simples: se o dado não poderia ser publicado, ele não entra aqui (LGPD, Lei 13.709/2018).
