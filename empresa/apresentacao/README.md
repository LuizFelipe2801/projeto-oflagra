# Apresentação e divulgação

Materiais para apresentar a empresa. Peças com o site de um cliente só entram com autorização dele.

## Peças

| Arquivo | Formato | Uso | Data |
|---|---|---|---|
| [`status-whatsapp.png`](status-whatsapp.png) | 1080×1920 | Status do WhatsApp (rascunho, a refazer mostrando trabalho real) | 2026-10-05 |

A fonte editável de cada peça é o `.html` de mesmo nome. Para gerar o PNG de novo:

```bash
chrome --headless=new --hide-scrollbars --window-size=1080,1920 --screenshot=status-whatsapp.png status-whatsapp.html
```

## Pitch

A empresa em uma frase: **site pronto, rápido no celular e medido, para o comércio de bairro de BH**.

Estrutura de apresentação para cliente:

> - O problema (o negócio não aparece para quem procura no celular)
> - O que é entregue (site, Google, vídeo, documentação, relatório)
> - Um caso real, com números de antes e depois
> - O que está e o que não está incluído
